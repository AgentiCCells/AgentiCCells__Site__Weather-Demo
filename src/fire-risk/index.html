Fire risk

IPMA's daily fire risk class (RCM, risco de incêndio rural) for each of the 278 mainland municipalities, for today and the next two days, on a scale of five classes from low to highest.

No fire-risk data for the islands: IPMA publishes no fire risk class for Madeira or the Azores.

By district

IPMA's file names municipalities only by their DICO code (two digits for the district, two for the municipality); it has no names. Only the municipalities that hold a town of this site are named, from that town; the rest keep their code and district, never a guessed name. District names are IPMA's.
