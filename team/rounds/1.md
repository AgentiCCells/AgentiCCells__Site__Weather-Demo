# Round 1

**Aim (conductor, 2026-11-18, about 16:40 UTC).** From the brief (Dinis, about 16:10 UTC: "explain how this works, explain what we do, but also explain how to use the raw data that we collect"): the whole site on one layout, with every weather source read live and the place view at its centre. Pick a town and see, together, its warnings, forecast, nearest station, sea, UV and fire risk, each with the source, the publisher, the time read and the card's terms beside it, and a plain message when a file is missing, stale or slow. One page per source. "Use the data" with copy-paste examples in JavaScript and curl, how to read a card and its terms, and how to build a page like this one. "How it was made". Use with AI (llms.txt, index.md). A link preview on every page. Behind the scenes generated from team/ and git log.

Starting point: the factory's seed page, and the shared gates, layout and loader copied from the IPMA-Data cell (1ab888d), each file saying where it came from.

Planned for later rounds: five designs under /d/ with a chooser (round 2), and whatever the reviewer finds.

- D3, "Use my location": no, not in round 1.
